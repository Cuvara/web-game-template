# GameVui — source matrix

Every claim this repository makes about GameVui, where it comes from, and how far to trust
it. Researched 2026-09-23.

## How to read this

| Class         | Meaning                                                                                                                                                                                               |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OFFICIAL`    | Stated on gamevui.vn by its operator (Công ty Cổ phần Mạng trực tuyến META). Quoted below.                                                                                                            |
| `THIRD_PARTY` | Stated somewhere other than gamevui.vn. Never a GameVui requirement.                                                                                                                                  |
| `INFERRED`    | Observed on the live site (how a hosted game is served, what a game page shows) or derived from an official statement. Not a published rule — GameVui may change it or never have meant it as a rule. |
| `UNKNOWN`     | Nothing found. Not "no requirement": no evidence either way.                                                                                                                                          |

**Current?** is `yes` when the page carried a 2026 date or was served live on 2026-09-23, and
says which.

HTTP 403. Every OFFICIAL quote below was read through headless Chromium (Playwright), which
passes the challenge and got HTTP 200. The support pages are:

No page on gamevui.vn is addressed to game developers. Probes of `/developer(s)`, `/sdk`, `/api`, `/upload`, `/submit`, `/publish` return GameVui's error page (research reviewer), and `dev.`, `developer.`, `sdk.`, `api.gamevui.vn` do not resolve. There is no developer portal, SDK
page, API reference, upload form or technical guideline linked from the site's navigation,
footer or support menu.
